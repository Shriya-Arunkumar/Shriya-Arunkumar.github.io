Robotics / Development roadmap

5DOF Robotic Arm

A five-degree-of-freedom robotic arm, with a staged roadmap from manual control to vision-guided manipulation and learned actions.

Project focus

5 DOF3D printingArduinoPython

Planned development · V1–V5

Overview

The project begins with a 3D-printed, manually controlled arm and builds toward coordinated motion, autonomous vision-guided pick-and-place, imitation learning, and language-conditioned manipulation.

The versions below describe the planned development progression and target capabilities, rather than completed results.

Development progression

  1. V1

    Make it move

    Build and manually control the physical robot.

  2. V2

    Make it precise

    Calculate joint angles and execute coordinated movements.

  3. V3

    Make it see

    Detect objects and perform autonomous pick-and-place.

  4. V4

    Make it learn

    Train the robot using human demonstrations.

  5. V5

    Make it understand Current ongoing research

    Combine language, vision, and learned manipulation policies.

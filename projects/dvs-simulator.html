Overview

A Dynamic Vision Sensor represents changes in a scene as events. This software simulator explores that principle: detecting per-pixel brightness changes instead of capturing full frames as the primary representation.

Research interest

The project is an entry point into neuromorphic and event-based vision. I’m interested in how alternative visual representations can inform perception in robotic systems.

Project scope

This is a software simulation of the sensing principle, rather than a physical sensor implementation. The source repository contains the implementation for further exploration.

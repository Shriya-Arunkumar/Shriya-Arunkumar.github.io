Dynamic Vision Sensor Simulator

A Python-based exploration of visual sensing through brightness changes rather than complete image frames.

Event Generation and Visual Results

The simulator transforms grayscale brightness into log-intensity changes. Changes exceeding a threshold generate positive (ON) or negative (OFF) events, visualized in red and blue; green boxes indicate clustered motion regions. This is software simulation, not physical DVS hardware.

Overview

A Dynamic Vision Sensor represents changes in a scene as events. This software simulator explores that principle: detecting per-pixel brightness changes instead of capturing full frames as the primary representation.

Simulation approach & outputs

A physical Dynamic Vision Sensor emits events when local brightness changes, rather than recording every pixel at fixed frame intervals. This Python exploration approximates that principle from image input: grayscale input is transformed to log-luminance, and changes crossing a threshold produce positive or negative events. Red marks indicate increasing brightness, blue marks decreasing brightness; spatial event clusters are displayed as green motion-region boxes. The implementation uses Python, NumPy, OpenCV, and SciPy. The public demonstration shows the software output. It should not be interpreted as evidence of physical sensor timing or fidelity.

Validation & limitations

Exact thresholds, event timestamp handling, noise assumptions, and performance parameters should be read from the released source. No measured comparison with a physical event camera or conventional frame-processing baseline is reported here.

Research interest

The project is an entry point into neuromorphic and event-based vision. I’m interested in how alternative visual representations can inform perception in robotic systems.

Project scope

This is a software simulation of the sensing principle, rather than a physical sensor implementation. The source repository contains the implementation for further exploration. Implementation reference: project README ↗
